# ⚡ Qonnect Frontend

Modern, Apple-minimalist dynamic QR code management dashboard and Design Studio built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**.

## 🚀 Features
- **Dynamic Dashboard**: Responsive card views, project folder filter tabs, and multi-select floating action bar.
- **Advanced QR Design Studio**: Real-time vector preview with curated luxury palettes, custom gradients, matrix dot shapes, corner eye customization, brand logo presets, and callout CTA frames.
- **Bulk CSV Importer**: Drag-and-drop CSV spreadsheet upload, editable table grid, and one-click ZIP download.
- **Branded 404 & Inactive Studio**: Interactive real-time mobile device frame preview for custom fallback pages.
- **Theme & Internationalization**: 1-click Dark/Light mode switching and full translations (EN, RU, UZ).

## 🛠️ Tech Stack
- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion**
- **TanStack React Query v5**
- **i18next**
- **Lucide React**

## 🏃 Local Run
